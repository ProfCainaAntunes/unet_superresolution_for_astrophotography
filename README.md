# Intelligent Image Processing for Astrophotography Enhancement

## Overview

This repository presents a deep learning approach for intelligent image enhancement in astrophotography captured under low-light conditions. The project is based on an adapted U-Net architecture designed to perform image restoration and perceptual enhancement while preserving relevant structural information.

The model was trained using a supervised learning strategy in which original astrophotography images are used as inputs and manually post-processed images are used as reference targets.

The implementation was developed using TensorFlow and executed in a Jupyter Notebook environment.

---

## Project Objectives

The primary objectives of this project are:

- Enhance astrophotography images captured in low-light conditions;
- Reduce image noise while preserving relevant visual structures;
- Improve contrast and color representation;
- Automate part of the astrophotography post-processing workflow using deep learning;
- Provide a reproducible training pipeline for future experiments and research.

## Model Architecture

The project uses an adapted U-Net convolutional neural network architecture for image enhancement.

The architecture includes:

- Encoder-decoder structure;
- Skip connections for feature preservation;
- Convolutional layers with nonlinear activation functions;
- Mixed precision support;
- Regularization strategies;
- Quantitative and qualitative evaluation pipelines.

The model was designed to process image patches and reconstruct enhanced outputs suitable for astrophotography applications.

## Dataset

All images required for training the model are located inside the following directory:

```text
images/dataset/256x256_dataset/
```

The dataset is composed of paired images following a strict naming convention.

Each original astrophotography image has a corresponding manually post-processed reference image.

### Naming Convention

The images follow the structure below:

```text
1_original.jpg
1_post_processed.jpg

2_original.jpg
2_post_processed.jpg

3_original.jpg
3_post_processed.jpg
...
```
Where:

* **_original.jpg** represents the original astrophotography image;
* **_post_processed.jpg** represents the manually enhanced reference image used as the training target.

The numeric identifier is used to associate each original image with its corresponding post-processed version.

### Dataset structure

```text
images/
└── dataset/
    └── 256x256_dataset/
        ├── 1_original.jpg
        ├── 1_post_processed.jpg
        ├── 2_original.jpg
        ├── 2_post_processed.jpg
        └── ...
```

## Reproducing the Project

This section explains how to reproduce the training process.

### 1. Clone the Repository

```bash
git clone <repository_url>
cd <repository_name>
```

---

### 2. Verify Dataset Availability

Before executing the notebook, ensure that the dataset is available inside:

```text
images/dataset/256x256_dataset/
```

No additional dataset download or extraction step is required if the repository already includes the images.

---

### 3. Adapt the Image Loading Logic

The original implementation was developed using Google Colab and loads images directly from Google Drive.

To reproduce the experiments locally, users must conceptually replace the Google Drive integration with local repository paths.

The required changes are:

* Remove the Google Drive mounting section;
* Replace Google Drive paths with local paths pointing to:
    ```text
    images/dataset/256x256_dataset/
    ```
* Maintain the original pairing logic based on the filename convention;
* Ensure that each _original.jpg image is associated with its corresponding ```_post_processed.jpg``` image.

No modification to the model architecture or training pipeline is required.

---

### 4. Execute the Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open:

```text
python_notebooks/unet_for_astrophotography_enhencement.ipynb
```

Run the notebook sequentially.
